# HL-FDE-DELIVERY-REPLICATION-001｜交付复制验证关卡 V1

## 本包验证什么
验证不同成员能否在既定范围内，用同一公共资产完成**可独立复核、质量等效**的交付，而不只是会解释走读卡。原开发者是否参与、成员总工时、创始人监督时长、返工与交接失败均需真实记录。

**三个门**：S0 安全走读 → G1 原任务独立复现 → G2 未见过的任务迁移。真实客户商业复制属未来 G3，不能由合成测试替代。

**当前初始事实**：FIX-009独立工程复审被报告为GO进入内部试用放行评审；真人走读 NOT_EXECUTED，设备和隔离 UNVERIFIED，实际试用仍 HOLD / NOT_AUTHORIZED。因此本包默认只有**纸面预备**获准，不允许用它直接启动软件、运行测试、改变网络策略、实际注入缺陷或部署。纸面完成只能标 PREPARED，不能标 G1/G2 PASS。

## 文件与分发
- `01-学员分发`：前置走读、G1岗位任务、日志/交接/复盘模板。没有G2密封题或考官判据。两名成员可直接取得，**但操作指令只在授权后执行**。
- `02-考官专用`：隐藏G2情景、独立判题、费用与监督记录、授权模板；不要提前分发。
- `03-原始材料只读副本`：原五份完整走读材料。原版不改动。

## 建议节奏（以完成条件为准，不承诺固定日程）
1. 创始人组织原走读：两人各≥8/10且K01–K08全部PASS；不符则补训/复测，保留首次记录。
2. 配齐设备/会话/入站与出站独立隔离方案；创始人另行书面批准人、机、数据、模式、范围、时段、停服责任。
3. A技术+B实施在批准副本内各自完成G1，互不代替；复核人进行独立复核。
4. 考官才发G2密封题，在合成数据/批准训练分支做迁移考核。
5. 汇总可比的成果、质量、人工时间、监督与复用数据。评审GO/HOLD/NO-GO；不自行推动生产/公开部署。
